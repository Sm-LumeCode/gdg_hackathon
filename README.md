# GDG Hackathon Application

This repository contains the codebase for our GDG Hackathon project, which includes a Flutter frontend and a Flask backend.

## Deployment

The application is deployed and accessible at the following link:

**Live Demo:** [https://web-flax-one-66.vercel.app](https://web-flax-one-66.vercel.app)

## Structure

- `flutter_frontend/`: Contains the Flutter application.
- `backend/`: Contains the Flask backend.

## Getting Started

To run this project locally, please refer to the respective frontend and backend directories for specific setup instructions.
